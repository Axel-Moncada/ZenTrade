# Evergreen — Contenido Atemporal

## Qué hay aquí

Posts educativos que no caducan. No mencionan fechas, precios ni ofertas temporales.
Funcionan hoy, en 3 meses y en un año. Son los posts que se comparten más y traen tráfico orgánico.

## Cómo usar este contenido

1. Publica estos posts intercalados con contenido de producto — ratio recomendado: 2 evergreen por cada 1 de producto.
2. Para pauta fría (cold audiences), usa el EV04 — su hook contraintuitivo detiene el scroll.
3. El EV03 es el más compartido en comunidades de traders — priorízalo para alcance orgánico.
4. El EV02 es el más ligado a ZenTrade — en la versión post-lanzamiento, agrega mención del producto al final.
