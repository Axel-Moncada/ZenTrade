# Banco de Hooks — ZenTrade

**Principio:** El hook es la primera línea. Si no detiene el scroll, el resto del copy no importa.
**Regla:** Nunca abrir con el producto. Abrir siempre con el pain del trader.

---

## Hooks por pain point

### Consistency rule (subestimado, alto impacto)

```
Pasé el profit target y me rechazaron igual. Esta fue la razón.
```

```
La regla que puede hacerte fallar aunque seas rentable — y que nadie te la explica bien.
```

```
Consistency rule: ningún día puede representar más del 30-50% de tu ganancia total.
La mayoría no calcula este número. Hasta que les pasa.
```

```
Puedes llegar al profit target. Tener el drawdown intacto. Y que te rechacen igual.
¿Sabes por qué?
```

---

### Revenge trading (el hook más poderoso para el nicho)

```
La razón #1 por la que los traders fallan evaluaciones no es la estrategia. Es el revenge trading.
```

```
El revenge trading no se siente como revenge trading cuando lo haces.
Se siente como recuperar lo que perdiste.
```

```
¿Y si tu app te dijera cuándo estás haciendo revenge trading antes de que te vueles la cuenta?
```

```
No fue la estrategia. Fue ese trade que tomaste sabiendo que no debías.
```

```
Cada evaluación fallada tiene un momento exacto en que se perdió.
El 80% del tiempo, ese momento fue en los 30 minutos siguientes a una pérdida grande.
```

---

### Métricas / profit factor

```
Un win rate del 70% puede hacerte perder dinero. Te explico cómo.
```

```
El número que los traders fondeados miran más que el win rate (y que nadie te enseña).
```

```
5 métricas que toda empresa de fondeo revisa — y que la mayoría de traders ignora.
```

```
Las empresas de fondeo no solo miden si llegaste al profit target.
```

---

### Psicología de evaluación

```
Por qué el 90% de traders que pasa la fase 1 falla la fase 2.
```

```
No es tu estrategia. Es tu psicología.
```

```
El día más peligroso de tu evaluación no es cuando pierdes.
Es el día después de tu mejor día.
```

```
La diferencia entre el trader que pasa pruebas de fondeo y el que las sigue comprando.
```

---

### Build in public / historia del fundador

```
Tardé 2 años en encontrar el journal perfecto para pruebas de fondeo.
Al final lo tuve que construir.
```

```
Fallé 3 evaluaciones de FTMO. Tenía buena estrategia. El problema era lo que pasaba el 20% del tiempo.
```

```
Construí lo que no existía: un journal en español para traders en evaluación.
```

```
Los traders de LATAM llevan años aprendiendo de los mejores — y operando con las peores herramientas.
Eso cambia.
```

### Hooks numéricos (detienen el scroll con datos)

```
85% de los traders que compra una evaluación de fondeo no la pasa.
```

```
El 90% no pasa la evaluación de fondeo.
No por estrategia. Por consistencia.
```

```
Un solo trade mal tomado puede representar más del 30% de tu pérdida total en una evaluación.
```

```
Tomaste un trade 18 minutos después de tu mayor pérdida del día.
Ese trade fue 2.4x tu tamaño promedio.
Fue tu cuarta pérdida consecutiva.
¿Qué registra ZenTrade? Esto exactamente.
```

## Framings que NO usar

- No abrir con el producto ("Zentrade es...") — abrir siempre con el pain
- No usar "software", "app", "herramienta" como palabra de apertura
- No prometer features de ZenMode a usuarios Starter en copy
- No usar "prop firm/s" en copy en español — usar "empresa de fondeo" o "prueba de fondeo" según contexto
- No usar "oportunidad", "colaboración", "te presento", "propuesta" en asuntos de email para influencers
- No hacer listas de beneficios del producto sin anclarlas primero en un pain concreto
