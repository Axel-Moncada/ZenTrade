# Historias — Stories de Instagram

## Qué hay aquí

Stories secuenciales de Instagram con instrucciones slide por slide.
Cada archivo describe el orden, el copy de cada pantalla, la dirección visual y el CTA.

## Cómo usar este contenido

1. Las stories se publican ANTES del post principal del día cuando hay ambas piezas.
2. Cada slide dura máximo 7 segundos si es imagen, 15 segundos si es video.
3. Usar el sticker de enlace (link sticker) en el último slide apuntando a zen-trader.com.
4. Las stories desaparecen a las 24h — no son evergreen. Publicar el mismo día que indica el archivo.
