## Cómo usar este índice

1. Revisa la columna **Estado** — empieza por los que dicen "Listo".
2. Mira la columna **Fecha sugerida** para saber qué publicar hoy.
3. Cuando publiques una pieza, actualiza el estado a "Publicado" y anota la fecha real.
4. Para encontrar el archivo completo, sigue el enlace en la columna **Pieza**.
