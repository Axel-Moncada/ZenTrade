# Posts — Contenido listo para copiar y pegar

## Qué hay aquí

Posts estáticos, threads de X/Twitter, carruseles de Instagram y posts de LinkedIn.
Todo el copy está listo para publicar — solo abre el archivo, copia el texto y publica.

## Cómo usar este contenido hoy

1. Identifica en el `00-INDICE.md` qué posts corresponden al día de hoy.
2. Abre el archivo de ese post.
3. Copia el copy de la sección de tu plataforma.
4. Sigue las instrucciones visuales incluidas en cada archivo para crear la imagen.
5. Agrega los hashtags de la sección correspondiente.

## Convenciones de nomenclatura

- `x-` → Post para X/Twitter
- `ig-` → Post para Instagram
- `linkedin-` → Post para LinkedIn
- `dia-N-` → Forma parte de la campaña de expectativa (días 1-5)
- `ev` → Evergreen (ver carpeta `/Evergreen/`)
