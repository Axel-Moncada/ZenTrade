# Videos — Guiones para TikTok, Reels e Instagram

## Qué hay aquí

Guiones completos para videos cortos (30-60 segundos) listos para grabar.
Cada archivo incluye: hook de apertura, narración hablada, texto superpuesto en pantalla, instrucciones de producción y CTA.

## Cómo usar este contenido hoy

1. Abre el guión que corresponde al día de tu calendario de contenido.
2. Lee el guión completo una vez para familiarizarte con el ritmo.
3. Graba preferiblemente con screen recording del dashboard + voz en off — ese formato convierte mejor que cara a cámara para demos de producto.
4. El texto superpuesto es obligatorio — el 60-70% de TikToks se consume sin audio.
5. Publica primero en TikTok, luego sube el mismo video como Reel en Instagram.

## Formato de producción recomendado (en orden de prioridad)

1. Screen recording del dashboard navegando + voz en off del fundador
2. Cara a cámara con fragmentos del dashboard intercalados
3. Texto animado sobre fondo oscuro (si no hay tiempo para grabar)

## Orden de producción recomendado

1. **`video-introductorio-credibilidad.md`** — Grabar PRIMERO. Es el ancla de todo lo demás.
2. **`formato-daily-operativa.md`** — Plantilla para el contenido diario. Empezar después del intro.
3. Los guiones de campaña de lanzamiento van después de tener 1-2 semanas de daily content.
